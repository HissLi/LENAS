# 调用 evaluate_validation · 验证候选

使用 `{{上下文}}` 中训练完成的候选编号、阶段、最佳检查点及其指纹、结构、冻结的验证清单、预处理和评分协议，调用 `evaluate_validation`。要求工具回读模型和检查点，逐一验证 pt_201–pt_240，记录实际病例清单与输入清单的一致性。

1. 使用 eval 模式、同一预处理且关闭训练增强，默认单次前向、关闭测试时增强（TTA）。网络预测及归一化标签恢复到 Gy；已经是 Gy 的参考剂量保持原值。把预测中的负值及可给剂量掩膜外的预测置零。记录剂量单位、后处理和推理设置。
2. 计算每个患者掩膜内的平均绝对剂量误差（Gy），再按患者等权平均得到 Dose score。与最佳检查点对应的在线验证值核对符号及量级；超出协议数值精度时列出差值，核对单位、清单、检查点和后处理后再用于排名。
3. 在原始、分开的 PTV 掩膜上计算 D1、D95、D99，在已勾画 OAR 上计算 Dmean、D0.1cc。D0.1cc 使用该病例的体素间距换算。按仓库公式求每个有效患者、结构、指标条目的预测与真值绝对差（Gy），将全部有效条目等权平均为 DVH score。报告每类指标条目数、每结构覆盖数和缺失原因。空掩膜或过小体积导致指标无定义时单列；同场候选使用同一组有效条目，评分异常引起的缺项必须复核。
4. 若提案指定了亚组或诊断指标，用训练阶段冻结的定义给出病例数、与对照配对的误差及方向。将诊断和用于排名的指标分栏；样本不足时标注覆盖情况。

返回 `validation_report` 及其指纹、检查点指纹、清单指纹、阶段、有效患者和条目数、两项未舍入均值及逐项结果引用。患者不全或有效分母不一致时返回异常与原因，等待重算后再作比较。

在 validation_report 中附 pair_id、实际配方及训练清单指纹，注明子集初筛、全量复核、筛选对照或正式阶段。各阶段均对同一 40 人验证清单评分，只在同阶段内排名。将日后需要配对比较的患者级分数保留在工具侧。

为 13 返回两个匹配作业的逐患者 Dose 误差、逐结构 DVH 有效条目及两个冻结亚组标签，供配对重抽样；确认验证患者集合及条目分母一致。
