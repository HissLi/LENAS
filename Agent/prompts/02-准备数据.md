# 调用 prepare_dataset · 准备数据与质检

你负责为后续工具建立可追溯的训练和验证输入。使用 `{{上下文}}` 中的原始或已转换数据根目录、患者清单、协议、缓存目录和运行号，调用 `prepare_dataset`。要求工具执行以下操作。

1. 按患者号核验训练 pt_1–pt_200、验证 pt_201–pt_240；检查数量、重复、交集和缺项。仅遍历这两个清单。原始 CSV 保留原件，在独立目录按项目 C3D 转换规则稠密化到 128³，统一反向切片和轴变换，CT 存储值减 1024；已有 NIfTI 则核验来源与方向，避免二次转换。
2. 对 CT、参考剂量、可给剂量掩膜、三种 PTV 和七种 OAR 核验形状、方向、间距、单位、稀疏索引范围和数值有限性。核实掩膜二值性、可给剂量区域非空、必要输入可读。将未勾画 ROI、已提供但为空的 ROI、文件损坏分开计数。必要文件缺失、标注剂量异常或坐标错位时，返回病例、字段及失败原因。
3. 核验训练器读到的九通道顺序：PTV70 + 0.9 × PTV63 + 0.8 × PTV56，随后为 Brainstem、SpinalCord、RightParotid、LeftParotid、Esophagus、Larynx、Mandible，最后为 CT。CT 限幅至 [−1024, 1500] 后除以 1000；标签为剂量 / 70，掩膜单独返回。记录转换前后的单位与范围。缓存原始 Gy 剂量、分开的 PTV 和空间信息，供统计和评分复用。
4. 固化两个清单及指纹、转换版本、有效病例数、ROI 缺失表和质检摘要。统计分析工具只接收训练部分的引用。验证质检信息用于确认数据完整性。相同源数据及配置允许复用已核验缓存。

返回共同回执，并单列 `train_manifest`、`val_manifest`、`prepared_data`、`qc_report` 的位置和指纹。若实际目录指向旧机器路径，返回当前解析结果及需要重新绑定的字段。遇到损坏数据时停止使用受影响的清单，保留诊断；不得静默删例或用零剂量顶替。

把全部 200 名训练和 40 名验证患者分别固化为独立清单并返回。向子集工具提供可按患者编号关联的训练数据引用；筛选子集时沿用已经核验的预处理版本。

为原始训练清单另建合格池 B 和逐例隔离台账。区分可验证的硬错误与待核实的统计异常；后者保留在 B 中供 12 提案。重新转换并回读修复项，对仍无法训练的记录注明证据和恢复条件；确认的重复副本保留一份。核对原始人数等于 B 加隔离人数。跨划分冲突或验证病例损坏须解决后再比较，不得缩减验证清单。
