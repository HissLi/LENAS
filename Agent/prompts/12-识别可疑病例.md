# 调用 audit_training_cases · 识别可疑训练病例

读取 {{上下文}} 中的训练患者原始清单、02 的逐例质检台账、03 在合格训练池上的逐例特征及运行种子。调用 audit_training_cases。输入限定为训练数据。目标是产生一份可复核、可撤销的排除提案。保存原始文件、病例号及清单版本。

1. 核对 02 的隔离台账。每个确定无法训练的病例必须有原始读取或空间一致性证据，例如参考剂量损坏、关键文件里的 NaN 或不可修复的坐标错位。先按相同规则重新转换并复核；修复成功则恢复。对内容完全重复的记录，核实 CT、剂量、掩膜、间距和来源，确认是同一病例副本后按固定编号保留一份。标识冲突或跨划分重合交回 02 处理。登记每次处理前后的数量及指纹。
2. 在合格训练池 B 构建患者级特征表。按解剖、采集和剂量三组取少量预先指定的特征，例如 PTV 并集体积、OAR 覆盖、体素间距、可给剂量体积分数、剂量分位数和边界梯度。缺失值保留缺失标志，连续值按训练集中位数填补，用训练中位数和四分位距缩放；删除恒定列，记录特征顺序和缩放参数。患者编号仅用于关联。
3. 默认在 B 上运行 k-medoids（欧氏距离，k 从 2 至 5），用平均轮廓系数选 k，平局取较小值。输出每簇人数、代表病例、患者到中心距离、簇内中位数和 MAD。默认提名距离大于簇内中位数加 3 倍 MAD 的病例。少于 5 人的簇、MAD 为零或轮廓系数不高于 0 时，将相应结果标为证据不足。用五个预先登记的种子各在 80% 的 B 上重复拟合，将全部患者分配至最近中心，报告异常标记出现次数。默认至少四次出现才进入下一步。小簇成员资格、缺少可选 OAR、高剂量或高训练损失单独出现时保留病例。
4. 对稳定离群病例回溯源文件，要求第二条独立证据，例如转换前后掩膜对齐检查提示局部偏移，或源剂量与参考元数据存在待核实的比例偏差。记录检查方法、原始测量和反例；同一梯度特征的两种统计不能充当两条证据。能确认并修复的问题返回 02，重建 B 和所有下游指纹。真实但少见的解剖变异保留。
5. 查看各簇、训练时定义的小体积或高梯度组以及稀有 OAR 的覆盖。默认最多提议排除 B 的 5%（向下取整）；保护人数少于 5 的预定组及稀有 OAR 的最后一例。符合条件者按重复提名次数、标准化距离降序，再按患者号排序。报告筛选前后分布；若发现亚组消失或关键覆盖损失，撤回相应提名。候选可以为空。
6. 返回按患者列出的「保留／硬质检隔离／建议试验性排除」、理由、证据引用、簇与稳定性、覆盖率变化，及 B、排除候选集 E、筛选池 F = B 去掉 E 的清单和指纹。逐例结果留在工具侧。冻结这一份提案后才允许读取验证分数；每次运行最多比较一份 F。只有 13 可以将 F 选为正式训练清单。
