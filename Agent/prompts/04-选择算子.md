# 为八个位置选择 component · 决策提示词

你收到 `{{上下文}}` 中的训练集统计、质检覆盖率、资源上限、对照 genotype 和候选名额。先复述与你的决策直接相关的实测证据（编号、数值、分母、单位），再提出对照和变体。没有训练集统计时回到工具阶段。

遵守下表的固定顺序和逐位置选项。

| 位置 | 候选 |
|---|---|
| down[0]、down[1]、up[0]、up[1] | `identity`、`conv`、`dep_conv`、`dil_conv`、`se_conv` |
| down[2]、up[2] | `identity`、`none` |
| down[3] | `avg_pool`、`max_pool`、`down_conv`、`down_dep_conv`、`down_dil_conv`、`down_se_conv` |
| up[3] | `up_conv`、`up_dep_conv`、`up_dil_conv`、`up_se_conv`、`up_interpolate` |

对照 NAS_29 取 down = [identity, dil_conv, none, down_dep_conv]，up = [dep_conv, dep_conv, none, up_interpolate]。按相对对照的改动数和统计信号强度安排候选。默认每个变体只替换一个位置。主分支的先后顺序和编码、解码方向都影响结构；重复算子合法，完整有序列表相同的候选应去重。

对每个候选给出完整的 down 和 up，同时填八行决策表，列为“位置｜所选算子｜替换或继承｜证据编号与解释｜可推翻假设的验证观察”。保留的槽位可引用 NAS_29 配置并说明为何保持控制变量。对改变的位置说明为什么改这里、优先于哪个替代算子、预期影响哪项指标或哪类结构、可能增加什么成本。保留备选顺序，供显存或形状预检失败时使用。证据薄弱时将候选明确标为探索性，目标仍按冻结协议评分。

例如，若实测小结构边界梯度偏高，可以对照 up[2] 的两种旁路设置，用同一组小结构的 D0.1cc 误差检查解释；若主指标变差，应如实保留这一结果。示例本身不能充当训练证据。最终返回候选编号、结构、父对照、改动位置、证据表、资源预期、优先级和决策记录引用。

本轮默认选出三个不同结构（含 NAS_29），交给 11 与各组超参数交叉。用基准参数估计可行性；保留全部三个可行结构进入子集试验。后续比较结构改动时引用相同配方的试验行。
