# 比较训练清单并决定正式训练用例

读取 {{上下文}} 中 12 冻结的基准池 B、筛选池 F、候选清单 E、覆盖表、08 选中的结构与配方及预算。目标是判断整份筛选策略能否改善该配对的验证表现。执行以下决策，只改变训练患者清单。

1. E 为空、缺少独立证据、覆盖保护未通过或预算不足时，以 B 作为正式训练池并记录原因。检查 B 与 F 的关系、病例数、清单指纹及排除理由。40 人验证集保持相同，测试集关闭。
2. 复用胜出配对在 B 上 5,000 步的全量复核作业。校验相同初始化种子、实际结构与配方、全局 batch、设备精度、增强策略、更新数、余弦周期、验证频率、检查点选择及验证清单。不能复用时仅在预算允许的情况下重跑匹配的 B 对照。以 05–07 在 F 上从头训练同样的 5,000 步。两组均按等更新数与等样本抽取总数比较，记录独立患者数、每例平均曝光和实际资源消耗。
3. 用同一患者的“F 的 Dose 误差减去 B 的 Dose 误差”求平均，报告患者级配对 bootstrap 的 95% 区间（固定种子，重抽 2,000 次）；报告 DVH score 差、相同有效条目数及 03 预先定义的小体积、高梯度亚组的配对 Dose 变化与人数。默认采用 F 的条件为总体 Dose 差的区间上界小于 0 Gy，DVH 差不大于 0 Gy，并且两个受保护亚组各至少有 5 个可评价病例且组均值均未变差。判据和亚组阈值在看验证结果前登记。这个区间描述固定训练种子下的病例间波动；报告此次验证集已用于选择架构和清单。
4. 任一判据未满足、结果不可比或缺少报告时选择 B。禁止看分数后逐例加回再重筛。记录胜出的清单、两个运行号、指纹、实际效应、不确定性和覆盖变化。配对试验只支持对整体数据策略的判断；单例状态仍保留原来的证据等级。
5. 输出 data_policy_record 以及 final_train_manifest，将其与 winner_record 一起交给主控。正式训练重新初始化，读取并核实该清单。需要回滚时以原始台账重建 B，使用新作业编号。
