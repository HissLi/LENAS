## 1. Dataset split

Official OpenKBP partition, enforced by patient-ID ranges:

| Split | Patients | Count | Role |
|---|---|---:|---|
| Train | `pt_1` … `pt_200` | 200 | optimization |
| Validation | `pt_201` … `pt_240` | 40 | checkpoint selection |
| Test | `pt_241` … `pt_340` | 100 | final evaluation only |

The split is defined in `DataLoader/dataloader_OpenKBP_C3D.py:122-124` (train/val), `NAS_42/online_evaluation.py:8` (validation), and `NAS_42/test.py:184` (test).

## 2. Input data and preprocessing

Identical for all models; implemented in `DataLoader/dataloader_OpenKBP_C3D.py`.

| Item | Value |
|---|---|
| Files read | `CT`, `dose`, `possible_dose_mask`, `PTV70/63/56`, 7 OARs |
| Input channels | **9** = PTV composite + 7 OAR masks + CT |
| PTV composite | `70/70·PTV70 + 63/70·PTV63 + 56/70·PTV56` |
| CT normalization | clip to `[-1024, 1500]`, divide by 1000 |
| Dose target | `dose / 70` |
| Loss mask | `possible_dose_mask` |
| Training augmentation | flips p=0.8 (axes 0,2), z-rotation p=0.3, translation p=0.8, max shift 20 |
| Validation transform | tensor conversion only |
| Dataset / DataLoader | 1000 samples/epoch, batch 2, shuffle, 4 workers |

## 7. Reproducibility notes

1. No random seed is set, so retraining the same genotype gives a slightly different score.
2. The prepared data directory is flat and contains all 340 patients; the split is enforced only by the patient-ID ranges above.
3. Effective weight decay is 3e-5, not the 1e-4 passed by `train.py`.
4. `wandb` runs offline (`WANDB_MODE=offline`).
5. Checkpoints (`*.pkl`, ~100–170 MB each) are git-ignored; only predictions, metrics, figures and reports are committed.
