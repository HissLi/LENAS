# OpenKBP 患者 CSV 文件说明

本文档说明每个患者文件夹中的 CSV 文件：

- 训练集：`train-pats/pt_1` – `pt_200`（200 名患者）
- 验证集：`validation-pats/pt_201` – `pt_240`（40 名患者）
- 测试集：`test-pats/pt_241` – `pt_340`（100 名患者，文件类型相同）

每个患者文件夹中最多有 **14 种 CSV 文件**。同一患者的所有文件共享同一个
**128 × 128 × 128 体素网格**，因此同一个拉平索引在所有文件中指向同一个体素。训练集和验证集的
文件格式与含义完全相同，区别只在于它们在流程中扮演的角色。

## 说明

- **训练集与验证集的区别在于使用角色，而不是文件格式。**
  - 训练时，`dose.csv` 是监督信号：`train_on_batch([ct, masks], dose)`。
  - 验证时，`dose.csv` 仅供 `DoseEvaluator` 计算参考 DVH 值和剂量分数使用。预测阶段模型只看到
    `ct.csv` 和结构掩膜。
  - 验证集是真正的留出集：`main.py` 只用 `train-pats` 训练。
- **同一患者的所有文件使用同一个 128³ 网格。** 数据以稀疏方式存储：
  - `ct.csv` / `dose.csv`：`index, value`（CT 强度 / Gy）
  - `possible_dose_mask.csv` 和所有 ROI 掩膜：`index,`，数值列为空——出现在索引列中表示
    “属于该结构”，未出现表示“不属于”
  - `voxel_dimensions.csv`：唯一非稀疏的文件——只有 3 个数字。
- **缺少某些 ROI 文件是正常的。** 表示该患者没有勾画该结构；DataLoader 会把对应通道填为零，
  评估器会跳过该 ROI 的 DVH 指标。`PTV70` 是唯一在全部 340 名患者中都存在的靶区。
- **`possible_dose_mask` 既不是靶区也不是器官**——它是剂量的定义域：掩膜之外的体素剂量恒为 0，
  因此它被用于对预测结果做掩膜，并作为剂量分数的分母。
- **单位：** 剂量为 Gy，体素间距为 mm，CT 强度按原始存储值使用（数据说明建议将其裁剪到
  0–4095），体素尺寸因患者而异。
- 数据说明中提到的 `unraveled_indices.csv` 并未包含在本数据集中。

## 重建为数组

```python
import numpy as np
import pandas as pd

def load_patient_file(path):
    """从一个患者的 CSV 文件重建 128x128x128 的数组。"""
    df = pd.read_csv(path, index_col=0)
    arr = np.zeros(128**3)
    if df["data"].isna().all():          # 掩膜：只有索引列表
        arr = arr.astype(bool)
        arr[df.index.values] = True
    else:                                 # CT 或剂量：稀疏数值
        arr[df.index.values] = df["data"].values
    return arr.reshape(128, 128, 128)
```
